# 💖 Projek Web Spesial - Cewe Tercantik

Website interaktif berbasis PHP dan JavaScript yang dibuat khusus untuk menampilkan apresiasi spesial dengan tema warna hitam-pink, animasi hujan emoticon love, serta galeri foto dinamis.

## ✨ Fitur Utama
* **Halaman Unggah (Index):** Antarmuka awal dengan tema gelap elegan beraksen pink untuk memilih dan mengunggah foto spesial.
* **Halaman Hasil (`hasil.php`):** 
  * Foto berputar/melayang halus dengan efek *glow*.
  * Ucapan spesial beranimasi: *"HI CEWE TERCANTIK DI HIDUP FATA"*.
  * Efek hujan emoticon love (`💖`, `💕`, `💗`, dll.) yang turun secara otomatis.
  * Stiker animasi lucu yang bergerak interaktif.
* **Penyimpanan Lokal:** Menggunakan PHP untuk memproses dan menyimpan foto yang diunggah ke dalam folder server secara otomatis.

## 🛠️ Teknologi yang Digunakan
* **PHP** (Backend / Pemrosesan Form & File)
* **HTML5 & CSS3** (Desain tata letak, gradasi warna, dan animasi keyframes)
* **JavaScript** (Efek animasi hujan love dinamis)
* **XAMPP / Apache** (Local Server Environment)

## 🚀 Cara Menjalankan Project di Lokal (XAMPP)
1. Pastikan aplikasi **XAMPP** sudah terinstal di komputer kamu.
2. Clone atau letakkan folder project ini ke dalam direktori `C:\xampp\htdocs\`[cite: 1].
3. Nyalakan layanan **Apache** melalui **XAMPP Control Panel**.
4. Buka browser (Chrome/Edge) dan akses tautan berikut:
